2. MATLAB INFORMATION

You can use Matlab in any of the three linux workstations (fourier and laplace).
The license of Matlab installed on these computers 
ALLOWS ONLY ONE USER TO USE MATLAB AT ONE TIME, 
so I set up a common user for Matlab. 
If you want to use Matlab on fourier.ee, and laplace.ee, please log in
as the common user:

user name: comm
passwd: matlab6

I strongly recommend you put all of your matlab code under one directory in YOUR OWN home directory, 
and change the permission of the code directory so that the common user can read and write the files in this directory.
By this means, when you login as the common user, you can still access your own matlab code, and you
donot need to transfer your code to the home directory of the common user. 

Enable the common user read and write your directory

chmod -R 775 directoryname

Disable the common user write to your directory

chmod -R 755 directoryname
